Project icons that mean something.

Three ideas for the project icons in Claude, working together in one sidebar. A larger set drawn in one style. Icons that pick themselves from what a project is about. And icons that tell you, at a glance, which project is working, which is done, and which one needs you.

  • Rename a project or add files and watch its icon follow.
  • Start a task and see the sidebar report back.
  • Pick your own icon any time. Auto steps aside.

    How it works

    Today a Claude project picks from a small set of general icons in seven colors, and the sidebar can't tell you what any project is doing. This concept changes three things.

    1 A set drawn for what people actually make

    212 original icons in 15 groups: clients and work, stores, money, websites and code, AI and data, writing, design, school, home and family, health, travel, food, hobbies, legal and admin, and symbols. Twelve colors tuned to sit on Claude's warm neutrals in light and dark.

    Every icon follows the same rules, so they look like one family:

    • 24 × 24 grid with a 2 point safe margin
    • 1.5 stroke at 24, thickening slightly at small sizes so they stay legible
    • Round caps and joins, 2 point corners on large shapes, no fills except tiny dots
    • Each icon sits on a soft tile in its color, the way a sidebar shows it

    2 Icons that pick themselves

    When you create or rename a project, Claude suggests an icon and a color from the project's name, its instructions, and the files in it. A spreadsheet of receipts leans toward money, a folder of .fig files toward design, a name like “Kitchen remodel” toward tools.

    The suggestion explains itself (“matched ‘invoice’ in the name”), groups colors by meaning so a sidebar sorts itself visually, and avoids giving two sibling projects the same icon in the same color. It runs instantly on the device, with no model call, so it can update as you type. Picking an icon yourself turns auto off for that project, and one click turns it back on.

    3 Icons that show status

    With Claude working in the background across projects, the sidebar should say what's happening without opening each one.

    • Working: a light travels around the tile, or fills it when progress is known.
    • Needs you: a clay dot at the top corner that gently breathes. The only state that asks for attention.
    • Done: a green check pops in once and clears when you open the project, like an unread mark.
    • Problem: a steady red mark, and the icon dims.

    Each state differs by position and shape as well as color, so it reads for color blind people too. Motion stops entirely when the system asks for reduced motion, and every state is announced to screen readers.

    Use it

    The icons are plain SVG. The status tile is a small web component with no dependencies:

    <script type="module" src="src/project-icon.js"></script>

<project-icon icon="store" color="violet" size="32"></project-icon>
<project-icon icon="invoice" color="green" status="needs-input"></project-icon>
<project-icon icon="browser" color="sky" status="working" progress="0.6"></project-icon>

    Suggestions come from one function:

    import { suggest } from './src/suggest.js';

suggest({ name: 'Acme Corp invoices', files: ['march.pdf', 'clients.xlsx'] });
// → { icon: 'invoice', color: 'green', confidence: 1,
//     reasons: ['“invoices” in name'], alternatives: [...] }
